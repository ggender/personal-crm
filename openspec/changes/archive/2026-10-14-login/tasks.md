# Tasks

Каждый сценарий из `specs/user-auth/spec.md`, `specs/data-ownership/spec.md` и новые сценарии `specs/contact-groups/spec.md` получают свой тест: название теста = название сценария, `describe` = название требования. Где какой тест — design.md, п. 12. Порядок в каждой задаче с тестами: сначала тест → запуск → тест красный, и причина та, что ждём (нет страницы, функции, таблицы, а не опечатка) → код → тест зелёный.

Агент не читает и не пишет `.env` ни на компьютере, ни на сервере: говорит, какую строку добавить или какую команду выполнить, и проверяет только наличие строк, не выводя значений.
