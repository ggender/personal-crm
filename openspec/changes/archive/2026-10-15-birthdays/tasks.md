# Tasks

Каждый сценарий из `specs/birthdays/spec.md` и новые и изменённые сценарии `specs/data-ownership/spec.md` получают свой тест: название теста = название сценария, `describe` = название требования. Сценарии, которые видны только на экране (порядок блоков, переход по нажатию, поиск, фильтр), — в Playwright, остальные — в Vitest (design.md, п. 8). Порядок в каждой задаче с тестами: сначала тест → запуск → тест красный, и причина та, что ждём (нет колонки, функции, поля на экране, а не опечатка) → код → тест зелёный.
