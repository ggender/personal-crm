# Личная CRM

Контакты людей, которых знаю лично: кто это, откуда знакомы, телефон и почта, заметки о разговорах.

## База данных (PostgreSQL в Docker)

Нужен запущенный Docker Desktop.

1. Настройки подключения лежат в `.env` (в git не попадает). Если `.env` нет — скопируй `.env.example` в `.env` и заполни значения.
2. Запустить базу: `docker compose up -d --wait`
3. Проверить, что работает: `docker compose ps` — в колонке STATUS должно быть `healthy`
4. Остановить: `docker compose stop` (данные сохраняются)

База доступна только с этого компьютера: `localhost`, порт из `POSTGRES_PORT` в `.env`.

Приложение собирает адрес базы из тех же переменных `POSTGRES_*` в `.env`. Если нужно подключиться к другой базе — можно вместо них задать одну строку `DATABASE_URL`.

## Первый запуск

Нужны Node.js 24 и pnpm.

1. Установить зависимости: `pnpm install`
2. Запустить базу (см. выше)
3. Создать таблицы: `pnpm db:migrate`
4. Наполнить тестовыми данными — 1000 контактов с заметками: `pnpm db:seed`
   Скрипт работает только с пустой базой: если контакты уже есть, он ничего не трогает.

## Запуск приложения

- Собрать и запустить: `pnpm build && pnpm start`
- Открыть: http://localhost:3000
- Остановить: `Ctrl+C` в окне терминала, где запущено приложение

Приложение открывается только на этом компьютере, из домашней сети его не видно.

Для разработки: `pnpm dev` — то же приложение, но изменения в коде видны сразу без пересборки.

## Как проверить главный сценарий

1. Открыть http://localhost:3000 — виден список всех контактов
2. «Добавить контакт» → заполнить имя → «Добавить контакт» — контакт подсвечен в списке
3. Набрать часть имени в поиске → открыть карточку → написать заметку → «Сохранить заметку»
4. Обновить страницу — заметка на месте
5. Открыть тот же адрес в другом браузере — те же контакты и заметки

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Запуск для разработки |
| `pnpm build` / `pnpm start` | Сборка и запуск |
| `pnpm db:generate` | Создать миграцию после изменения схемы в `src/db/schema.ts` |
| `pnpm db:migrate` | Применить миграции к базе |
| `pnpm db:seed` | Заполнить пустую базу тестовыми контактами |
| `pnpm lint` / `pnpm typecheck` | Проверки кода |
